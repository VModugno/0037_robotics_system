# COMP0037 2026/27 — Coursework 1 Starter Code (`cw1_starter/`)

Starter environments for the **MedBot (Autonomous Hospital Pharmacy & Sterile Lab)** coursework (Weeks 01–05):

- `q1_bandits_hospital.py` — 8-bay hospital dispatch/charging bandit (stationary & drifting non-stationary modes).
- `q2_hospital_ward.py` — 8×12 stochastic `HospitalWardEnv` (walls `#`, automatic doors `D`, sterile ICU `I`, biohazard spill `B`, start `S`, goal `G`).
- `q3_sterile_arm.py` — 2-DoF planar `SterileArmEnv` with hard joint limits and circular centrifuge keep-out obstacle.
- `q4_payload_sim.py` — `medbot_payload_trolley` MJCF model with variable top payload mass, mast damping, and floor friction.

Run each file directly to execute its self-test before implementing your coursework extensions.
